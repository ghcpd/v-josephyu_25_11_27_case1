- README command: `python app.py --host=0.0.0.0 --port=8080`
- Error: `app.py` ignores CLI args; Flask runs on default 127.0.0.1:5000
- Trace: Using provided command, server still binds to 127.0.0.1:5000 (see console logs)

2) Missing docs: No documentation for actual routes
- README references `/signup`, `/signin`, `/profile`, `/api/register`, `/api/login`
- Implementation provides `/register`, `/login`, `/logout`, `/dashboard`
- Evidence: 404 Not Found on `/signup` and `/signin`; no `/profile` or `/api/*` routes

3) Incorrect docs: CSRF configuration env var name
- README says use `FLASK_SECRET`
- Implementation uses `SECRET_KEY` in `app.config`
- Evidence: Setting `FLASK_SECRET` has no effect on CSRF token generation

- README body uses `{ "user", "pass", "mail" }`

- Evidence: Submitting JSON with those keys would fail mapping to WTForms fields

- Evidence: No Redis config or code; `app.db` created at project root
