## 📋 Mismatches / Defects Summary (from defects.txt)
Defects found and reproduction steps:

1. Virtualenv activation instructions
   - README: `python3 -m venv .venv` and `source .venv/bin/activate`
   - Problem: Windows PowerShell uses `python -m venv .venv` and Activate (or `source` in POSIX)
   - Repro: On Windows, `python3` not found / `source` not recognized.

2. Running the app with host/port flags
   - README: `python app.py --host=0.0.0.0 --port=8080`
   - Problem: `app.run(debug=True)` in app.py ignores CLI args; use `flask run` or edit app.py.
   - Repro: `python app.py --host=0.0.0.0 --port=8080` starts server at default `127.0.0.1:5000`.

3. Route name mismatches
   - README: uses `/signup` and `/signin`
   - Actual: uses `/register` and `/login`.
   - Repro: GET `/signup` and `/signin` -> 404.

4. API endpoint mismatch
   - README: `/api/register`, `/api/login`
   - Actual: there is no `/api` blueprint. UI routes only.

5. Password minimum length mismatch
   - README: min length = 3
   - Actual: WTForms validators enforce `Length(min=6, ...)` in auth.py.
   - Repro: register with 3-char password -> validation error.

6. Email optional vs required 
   - README: claims email is optional
   - Actual: `email` field is required in `RegisterForm` and DB column is NOT NULL and UNIQUE. Submission without email fails.

7. Database path mismatch 
   - README: `data/database.sqlite3` 
   - Actual: default DB is app.db (set in app.py).

8. Session store mismatch
   - README: sessions stored in Redis
   - Actual: app uses default cookie-based sessions (no Redis).

9. Environment variable mismatch for secret
   - README: `FLASK_SECRET` recommended
   - Actual: app uses `app.config['SECRET_KEY'] = 'replace-with-a-strong-secret-key'` instead of reading `FLASK_SECRET`.

10. Run tests command in README
   - README suggests `bash run_tests.sh`, but file was missing; now we've added a run_tests.sh.
