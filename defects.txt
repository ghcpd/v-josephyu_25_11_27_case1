# DEFECTS FOUND IN README.md

This document lists all defects found when comparing the README documentation with the actual implementation.

================================================================================
DEFECT #1: Incorrect Quick Start Command
================================================================================

**README States:**
```bash
python app.py --host=0.0.0.0 --port=8080
```

**Actual Behavior:**
The app.py file does not parse command-line arguments. The code is:
```python
if __name__ == '__main__':
    app.run(debug=True)
```

**Error When Following README:**
```
$ python app.py --host=0.0.0.0 --port=8080
usage: app.py [-h]
app.py: error: unrecognized arguments: --host=0.0.0.0 --port=8080
```

**Reproduction Steps:**
1. Run: python app.py --host=0.0.0.0 --port=8080
2. Command fails with unrecognized arguments error

**Correct Command:**
```bash
python app.py
# Or if you need custom host/port:
flask run --host=0.0.0.0 --port=8080
# Or use environment variables:
# set FLASK_APP=app.py (Windows) or export FLASK_APP=app.py (Linux/Mac)
# flask run --host=0.0.0.0 --port=8080
```

DEFECT #5: Missing confirm_password Field
================================================================================

**README States:**
"Register a user at `/signup` with fields: `username`, `email`, `password`, `confirm_password`"

**Actual Implementation:**
The registration form only has three fields: username, email, and password.
There is NO confirm_password field.

**Evidence from Code (auth.py, lines 15-18):**
```python
class RegisterForm(FlaskForm):
    username = StringField('Username', validators=[DataRequired(), Length(min=3, max=32)])
    email = StringField('Email', validators=[DataRequired(), Email(), Length(max=255)])
    password = PasswordField('Password', validators=[DataRequired(), Length(min=6, max=128)])
    submit = SubmitField('Register')
```

**Reproduction Steps:**
1. Navigate to /register
2. Inspect form fields
3. Only three input fields present: username, email, password
4. No confirm_password field exists

The `DataRequired()` validator makes email mandatory.

DEFECT #9: No Redis Session Storage
================================================================================

**README States:**
"Sessions are stored server-side in Redis"

**Actual Implementation:**
Sessions are NOT stored in Redis. The application uses Flask's default session management
(client-side cookie-based sessions with Flask-Login).

**Evidence:**
1. No Redis imports in any file
2. No Redis configuration in app.py
3. No redis or Flask-Session in requirements.txt
4. Flask-Login uses cookie-based sessions by default

**Reproduction Steps:**
1. Search codebase for 'redis' - no results
2. Check requirements.txt - no Redis-related packages
3. Sessions are stored in cookies, not Redis

DEFECT #11: FLASK_SECRET Environment Variable Not Used
================================================================================

**README States:**
"Use environment variable `FLASK_SECRET` to configure CSRF"

**Actual Implementation:**
The SECRET_KEY is hardcoded in app.py and does not read from FLASK_SECRET environment variable

**Evidence from Code (app.py, line 8):**
```python
app.config['SECRET_KEY'] = 'replace-with-a-strong-secret-key'
```

**Correct Implementation Would Be:**
```python
import os
app.config['SECRET_KEY'] = os.environ.get('FLASK_SECRET', 'replace-with-a-strong-secret-key')
```

**Reproduction Steps:**
1. Set environment variable: export FLASK_SECRET=my-secret-key (or set FLASK_SECRET=my-secret-key on Windows)
2. Run application
3. Check app.config['SECRET_KEY']
4. Value is still 'replace-with-a-strong-secret-key', not 'my-secret-key'

DEFECT #12: Setup Command Missing email_validator
================================================================================

**README States:**
```bash
pip install flask flask-login flask-wtf wtforms
```

**Actual Implementation:**
The application requires `email_validator` package for email validation in WTForms,
but it's not listed in the setup instructions.

**Error When Following README:**
```
ImportError: email_validator is not installed. Install it with: pip install email-validator
```

**Evidence from Code (auth.py, line 16):**
```python
email = StringField('Email', validators=[DataRequired(), Email(), Length(max=255)])
```

The `Email()` validator requires the email_validator package.

**Correct Command:**
```bash
pip install flask flask-login flask-wtf wtforms email_validator
```

**Reproduction Steps:**
1. Create fresh virtual environment
2. Run: pip install flask flask-login flask-wtf wtforms
3. Try to access /register route
4. Get ImportError for email_validator
