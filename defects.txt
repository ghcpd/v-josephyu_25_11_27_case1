DEFECT #1: Incorrect Quick Start Command
================================================================================
Severity: HIGH - Command will fail
Location: README.md - Quick Start section
Documentation states:
  python app.py --host=0.0.0.0 --port=8080

Current implementation:
  app.py contains: app.run(debug=True)

Problem:
  Flask's built-in development server does not accept --host and --port as 
  command-line arguments when passed directly to app.py. The app.run() method 
  ignores these CLI arguments.

Error Trace:
  When running: python app.py --host=0.0.0.0 --port=8080
  Result: These arguments are ignored; server runs on default localhost:5000
  Expected: Server should run on 0.0.0.0:8080

Reproduction Steps:
  1. Follow README setup steps
  2. Run: python app.py --host=0.0.0.0 --port=8080
  3. Observe: Server starts on localhost:5000 (ignores arguments)

Correct Usage:
  Option A: python app.py  (uses default localhost:5000)
  Option B: FLASK_ENV=development FLASK_APP=app.py flask run --host=0.0.0.0 --port=8080
  Option C: Modify app.py to use: app.run(host='0.0.0.0', port=8080, debug=True)

DEFECT #8: SECRET_KEY Not Read from Environment Variable
================================================================================
Severity: MEDIUM - Security and configuration issue
Location: README.md - Notes and Setup sections
Documentation states:
  Use environment variable FLASK_SECRET to configure CSRF

Current implementation:
  app.config['SECRET_KEY'] = 'replace-with-a-strong-secret-key' (hardcoded)

  environment variable, but app.py ignores it and uses hardcoded value.

Error Trace:
  Setting environment variable FLASK_SECRET=my-secret-key
  Result: App uses hardcoded key, not the environment variable
  Expected: App should use FLASK_SECRET value

Reproduction Steps:
  1. Set: export FLASK_SECRET=production-secret-key
  2. Start the app
  3. Observe: App uses hardcoded key 'replace-with-a-strong-secret-key'
  4. Expected: App should use 'production-secret-key'

Correct Implementation:
  app.config['SECRET_KEY'] = os.environ.get('FLASK_SECRET', 'replace-with-a-strong-secret-key')
